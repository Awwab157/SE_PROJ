# API reference

Generated by `scripts/gen_api_docs.py` from the registered MCP tools and pydantic models. Transport: stdio.

Every successful result has `structuredContent` (matching the output schema) plus two text blocks: a
short `summary` and the same data as JSON (UI-1). Errors are results with `isError: true` and
`structuredContent = {"error": {"code", "cause", "next_step", "details"}}` (UI-3).

Quota costs are upper bounds reserved before the first call; unused quota is released afterwards and
cache hits cost nothing. Bucket limits and per-method costs are in `config/quota.yaml`.

| Tool | Writes to YouTube | Quota (default config) |
|---|---|---|
| `find_similar_videos` | no | up to search_calls 3, units 305 (minimum search_calls 1, units 103) |
| `find_similar_channels` | no | up to search_calls 2, units 235 (minimum search_calls 1, units 105; /c/ URLs +1 search) |

| `create_playlist` | **YES** | units 50 (playlists.insert) + 50 per video (playlistItems.insert), reserved atomically |
| `start_authorization` | no | 0 |
| `revoke_authorization` | no | 0 |
| `clear_cache` | no | 0 |

|---|---|---|

## Error codes

| Code | Meaning |
|---|---|
| `internal_error` | Retry the request. If it keeps failing, check the server log (it is redacted). |
| `invalid_input` | Correct the input described in the cause and call the tool again. |
| `not_found` | Check the URL or ID. The item may be private, deleted or terminated. |
| `forbidden` | The authorised account cannot access this item. Check its privacy settings. |
| `quota_exceeded` | The YouTube API daily quota is used up. Try again after midnight Pacific Time. |
| `rate_limited` | YouTube is rate limiting requests. Wait a minute and try again. |
| `youtube_signup_required` | This Google account needs a YouTube channel before it can create playlists. Create one at https://www.youtube.com/create_channel and try again. |
| `reauthorization_required` | Call start_authorization to sign in again. Tokens for apps in Google 'Testing' mode expire after 7 days. |
| `transient_error` | A temporary YouTube or network error occurred. Try again shortly. |
| `authorization_required` | Call start_authorization to connect a YouTube account (read-only access). |
| `write_scope_required` | Playlist creation needs the 'youtube' scope. Approve the extra permission when the browser opens, then call create_playlist again. |
| `quota_budget_exceeded` | Reduce the request size (for example a lower limit) or wait for the daily reset. |
| `proposal_not_found` | Call propose_playlist to create a new proposal. |
| `proposal_expired` | Proposals expire after 10 minutes. Call propose_playlist again. |
| `proposal_declined` | This proposal was declined. Call propose_playlist to start again. |
